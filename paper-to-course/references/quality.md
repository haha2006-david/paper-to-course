# 交付前检查与已有来源复用

读者仍只看到精简重点、原图/公式、自测和复习卡。本文件用于生成过程，不增加用户正文的固定栏目。

## 先复用已读来源

用户给了已有全文阅读材料或`nature-reader`的`paper.md`、`source_map.json`时，先核对论文身份、版本和实际阅读范围。复用其中已定位的文本块、术语和图表；缺失或低置信度部分仍回查原PDF。无需为了生成短解读再做一次全文翻译，也不要求安装Nature系列skill。

来源分为：有可靠PDF页序号、只有结构锚点、只有局部材料。结构锚点不能编成PDF页码，印刷页码和PDF第几页分别记。已有source map是来源材料，不是已被独立验证的真值。

可给`lesson.json`的对应`sources`条目加入以下可选字段，保持原来的`locator`、`kind`等字段：

```json
{"id":"s1","block_ids":["S021","C003"],"pdf_pages":[7,8]}
```

仅填写实际存在的锚点和正整数PDF页序号；无页码时省略`pdf_pages`，保留章节、图号或块ID。跨论文引用不能复用同一图像/块ID；先确认来源对应的是同一篇、同一版本。额外外部背景仍有自己的引用，不冒充原论文证据。

## 检查成品

在skill目录下运行，或用本skill的绝对路径调用脚本：

```text
python scripts/audit_brief.py lesson.json --report audit.json
```

有已有source map才加：

```text
python scripts/audit_brief.py lesson.json --source-map source_map.json --report audit.json
```

脚本检查：格式及引用ID；正文实际显示字段的中文字数（包含必要背景和图导读）；原图是否重复出现；可选来源块是否存在、PDF页序号是否与其一致；数据中是否另藏大量不显示的解释文字。自测、复习卡、图内文字和出处弹窗不算正文，另外报告统计范围，不据字数推算理解时间。

默认700中文字是压缩提醒，不是删掉必要结果的硬门槛；复杂证据确需超出时保留，并说明原因。数据中的旧字段可能重复正文；警告需判断是否只是兼容字段，不能为消除警告而删掉有用内容。当前渲染器实际显示`lesson.example`、`steps`、`output`和就近公式；单独的`conclusions`列表仅作内部检查，重要结论仍须在可见的`body`、`observation`、`overview`等字段中交代。旧字段不得存放一份新的长讲义。

脚本返回非零时先修复错误；警告逐项检查。它只验证引用连接和产物一致性，不验证原PDF页码真实性、科学推断或学习效果；未给source map时明确标为未检查，不能把ID可解析当成来源真实支持结论。

然后运行`check_math.py`检查公式，并人工按coverage清单核对主要发现、比较条件、阴性结果与边界。不得用脚本的零错误冒充内容已独立通过。

## 按论证选择重点

不强迫所有论文采用方法论文叙事：

| 贡献类型 | 最少要保住的证据链 |
|---|---|
| 方法/工具 | 输入和关键改动 → 强基线/消融 → 实际收益与代价 |
| 发现/机制 | 现象 → 干预/对照 → 支持的机制与替代解释 |
| 资源/基准 | 来源及纳入 → 标注/划分 → 实际用途验证与代表性 |
| 临床/人群 | 设计与人群 → 结局/效应及不确定性 → 偏倚与外推边界 |
| 材料/工程 | 条件和制备 → 同条件性能比较 → 机制证据、稳定性与成本 |
| 理论/综述/观点 | 命题或问题 → 假设/证据分组/推理 → 分歧与未证明事项 |

这些只是写作镜头，不是跨学科有效性认证；混合贡献可保留必要的第二条主线，不增加固定长章节。
