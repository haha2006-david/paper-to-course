# 从全文提炼重点，再检查讲义遗漏

每个主题先从原文列出必须保住的内容及位置，再查讲义的落点。状态只有 covered / partial / unavailable / not_applicable；不给伪精确的总覆盖率。“covered”表示已在讲义交代，不代表经过独立专家验证。

| topic | 必查信息 |
|---|---|
| problem | 问题、已有工作与真实缺口；作者修辞与已证实结果分开 |
| method | 核心新意、完整输入→关键步骤→输出、必要假设和对照；不能只解释一个术语 |
| results | 全部主要任务/结局及结果方向、数字、比较条件与不确定性 |
| robustness | 关键图表、消融/敏感性、负结果、失败条件；没做的不要补造 |
| conclusions | 观察与作者解释分开；理论结论保留必要假设 |
| limitations | 作者报告与读者推断分开，泛化边界及证据缺口 |
| use | 能用于什么、不能外推什么、复现/引用需回看的位置 |

按论文类型调整：综述保留检索/纳入方式（若报告）、证据分组、共识与分歧；理论保留命题、必要假设、证明路线；实证保留设计、终点、效应与不确定性；方法论文保留基线、消融及资源代价。

关键图表无法读取时标 partial，并说明影响哪些结论；图注不是已看原图的证据。仅摘要不能标 full access。表格与正文有冲突时保留双值与双定位，禁止静默挑一个。
